# MiniMarkovChain
Takes in the data from a text file and generates a list of words from it

This was made in around 2 hours to explore my understanding of markov chain as a personal project

names.txt are from [here](https://github.com/dominictarr/random-name/blob/master/first-names.txt)

# How to use
1. Change INPUT_FILE in main.py to the file u want to feed it
2. Run main.py
